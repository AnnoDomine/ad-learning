# Step 1 - Docker

## Dockerfile

```Dockerfile
FROM python:3-slim

WORKDIR /api

RUN [ "useradd", "apiuser" ]

COPY learningsteps/api/requirements.txt .

RUN [ "pip", "install", "--no-cache-dir", "-r", "requirements.txt" ]

COPY learningsteps/api/ .

USER apiuser
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]

EXPOSE 8000
```

### Details

| Line | Details |
| :-- | :-- |
| `FROM python:3-slim` | Use slim template for current stable `3.x.y` python version |
| `WORKDIR /api` | Define the working directory to `api` |
| `RUN [ "useradd", "apiuser" ]` | Create a non-root user |
| `COPY learningsteps/api/requirements.txt .` | Copy only `requirements.txt` to image |
| `RUN [ "pip", "install", "--no-cache-dir", "-r", "requirements.txt" ]` | Install `requirements.txt` dependencies |
| `COPY learningsteps/api/ .` | Copy rest of learningsteps api to image |
| `USER apiuser` | Switch to non-root user |
| `CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "8000"]` | Start api |
| `EXPOSE 8000` | Expose port 8000 to network |

> Every `RUN` step is cached and only runs again when changed.  
> It is highly recommanded to not run Docker as `root`.

### Deploy to ACR

```bash
# Generate the container link
export CONTAINER_LINK="$ACR.azurecr.io/${CONTAINER}:$CURRENT_VERSION"

# Register to container registry if needed
az provider register \
  --namespace Microsoft.ContainerRegistry \
  --wait

# Create an Azure Container Registry
az acr create \
  --resource-group $RG \
  --name $ACR \
  --sku Basic \
  --location $REGION

# Troubleshooting on WSL
# Path to Docker Desktop needs to be exported
export PATH=$PATH:"/mnt/c/Program Files/Docker/Docker/resources/bin"

# Login to the ACR
az acr login --name $ACR

# Update the local container tag
docker tag "$CONTAINER:$CURRENT_VERSION" "$CONTAINER_LINK" 

# Push the image to azure
docker push "$CONTAINER_LINK"

# Verify image is pushed
az acr repository list --name $ACR -o table

# Delete local container
docker rmi "$CONTAINER_LINK"

# Pull fresh image from Azure
docker pull "$CONTAINER_LINK"

# Set local the DB URL
export DATABASE_URL="postgresql://postgres:postgres@localhost:5432/learning_journal"

# Start the image
docker run -d -p 8000:8000 -e DATABASE_URL --name "$CONTAINER" "$CONTAINER_LINK"
```
